# Entry note

Line: "The office printer only jams when the CEO walks past, so IT now hides behind it taking bets on his next visit."

Code points: 110 (within the 1–200 limit).

Why this line: a fresh angle — not the "this meeting should have been an email" joke the bounty description itself uses as its example, and not a generic complaint about meetings or Mondays. The joke turns on a specific, recognisable office detail (the printer that only jams when the CEO walks past) told as a small concrete scene, and the punchline flips IT from fixers to bookmakers on the last clause. It reads unmistakably as office life, it is one tight sentence, and it needs no explanation.
